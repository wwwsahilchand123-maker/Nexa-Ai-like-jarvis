# Contributing to NEXA AI

NEXA AI is a personal AI-assistant project. Contributions should keep the assistant reliable, understandable, and safe to run locally.

## Guidelines

- Keep features modular and avoid unnecessary changes to unrelated files.
- Never commit API keys, access tokens, private prompts, or personal data.
- Document new commands, integrations, and environment variables.
- Test changes locally before opening a pull request.

## Pull requests

Describe the feature or fix, testing performed, and any new permissions or external services required. Prefer small, reviewable changes over large unrelated refactors.
